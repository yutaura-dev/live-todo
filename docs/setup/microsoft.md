# Microsoft（Outlook・Teams）につなぐ準備

live-todo は、Entra ID（旧 Azure AD）に自分で登録したアプリで、職場のアカウントに device code 認証でサインインする（[ADR-0017](../decisions/0017-microsoft-graph-device-code.md)）。ほかのアプリの client ID は借りない。

## 1. アプリを登録する

1. [Microsoft Entra 管理センター](https://entra.microsoft.com/) で「アプリの登録」→「新規登録」を開く
2. 次のように登録する
   - 名前: `live-todo`（何でもよい）
   - サポートされているアカウントの種類: 「この組織ディレクトリのみに含まれるアカウント」
   - リダイレクト URI: 入れない
3. 登録したアプリの「認証」で、「詳細設定」の「パブリック クライアント フローを許可する」を「はい」にして保存する（device code 認証に要る）

会社のテナントでアプリの登録が許されていなければ、管理者に頼む。

## 2. 権限を足す

「API のアクセス許可」→「アクセス許可の追加」→「Microsoft Graph」→「委任されたアクセス許可」で足す。

| 権限 | 使う機能 | 管理者の同意 |
|------|----------|--------------|
| `offline_access` | リフレッシュトークン（毎回サインインしないため） | 要らない |
| `User.Read` | 自分のアドレスの確認 | 要らない |
| `Calendars.Read` | Outlook の予定 | 要らない |

Teams とメールに対応したら、次も足す（まだ要らない）。

| 権限 | 使う機能 | 管理者の同意 |
|------|----------|--------------|
| `Chat.Read` | Teams のチャット | 要らない |
| `Team.ReadBasic.All`・`Channel.ReadBasic.All` | 入っているチームとチャネル | 要らない |
| `ChannelMessage.Read.All` | チャネルのメッセージ（メンション・スレッドの返信） | **要る** |
| `Mail.ReadWrite` | メールの仕分けと片付け | 要らない |

テナントの設定によっては、管理者の同意が要らない権限でも、ユーザーが自分で同意できないことがある。そのときは管理者に「管理者の同意を与える」を押してもらう。

## 3. live-todo に書く

1. アプリの「概要」から「アプリケーション（クライアント）ID」と「ディレクトリ（テナント）ID」を写す
2. 設定画面の「Microsoft（Outlook・Teams）」でアカウントを足し、2 つの ID と、職場のデータを送ってよい LLM Profile を選ぶ。使う機能にチェックを入れて保存する
3. 「サインインする」を押す。開いたブラウザでコードを入れ、職場のアカウントでサインインする

使う機能を変えたら、求める権限が変わるのでサインインし直す。

## うまくいかないとき

- `AADSTS7000218` などで断られる: 「パブリック クライアント フローを許可する」が「はい」になっているか
- `AADSTS65001`（同意がない）: 権限に同意していないか、管理者の同意が要る
- サインインの画面で止められる: 会社の条件付きアクセスで device code 認証が止められていることがある。管理者に確かめる
